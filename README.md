# 한글 모아모아 헬퍼

메이플스토리 미니게임 **한글 모아모아**에서 매 턴 나오는 블록 3개를 어디에, 어떤 순서로 놓을지 추천해 주는 도구입니다.

> 비공식 팬 제작 도구이며 넥슨/메이플스토리와 관련이 없습니다. 게임 화면을 읽거나 조작하지 않고, 사용자가 직접 입력한 블록만으로 계산합니다.

## 바로 사용하기 (설치 불필요)

1. 이 저장소에서 **`moamoa.html`** 파일을 내려받습니다. 파일을 연 뒤 오른쪽 위 다운로드 버튼(Download raw file)을 누르면 됩니다.
2. 내려받은 파일을 **더블클릭**하면 크롬이나 엣지에서 열립니다. 인터넷 연결은 필요 없습니다.
3. 새 게임을 시작할 때 **판 초기화**를 누릅니다.
4. 게임에 나온 블록 3개를 아래 블록 목록에서 클릭합니다. 번호 입력칸에 `17 19 9`처럼 입력해도 됩니다.
5. 판에 **A → B → C** 순서와 위치가 표시됩니다. 게임에서 그대로 놓고 **추천대로 놓기**(Enter)를 누릅니다.

### 팁
- **놓는 순서(A→B→C)를 꼭 지켜 주세요.** 같은 자리라도 순서를 바꾸면 여러 줄 동시 삭제 보너스를 놓칠 수 있습니다.
- 회전과 반전은 헬퍼가 알아서 고릅니다. 블록은 번호만 고르면 됩니다.
- 잘못 놓았으면 **판의 칸을 클릭**해서 실제 게임과 똑같이 맞춰 주세요. 줄이 꽉 차면 자동으로 지워집니다.
- **지운 줄 수**가 게임 화면과 다르면 숫자를 클릭해 고칩니다. 단계(30/60/100/150줄)에 따라 블록 분포가 달라지므로 맞춰 두면 추천이 정확해집니다.
- **1칸 아이템 추천** 버튼은 1칸 아이템을 놓을 최적 자리를 알려 줍니다.
- 되돌리기는 `Ctrl+Z`입니다.

## 게임 규칙 (헬퍼가 가정하는 것)

- 판은 가로 10 × 세로 16, 블록은 19종입니다.
- 가로줄이 꽉 차면 지워지고, 위의 블록은 내려오지 않습니다.
- 블록 3개를 순서 상관없이 모두 놓아야 다음 3개가 나오며, 회전과 반전이 가능합니다.
- 점수: 블록 하나로 n줄을 동시에 지우면 300 × n²점입니다(1줄 300, 2줄 1,200, 3줄 2,700 …).

## 동작 방식

1. **빔 탐색**: 블록 3개의 순서, 회전, 위치 조합을 탐색합니다. 중간에 줄이 지워지는 것도 반영합니다.
2. **평가 함수**: 고립된 빈칸, 가로/세로 전이 수, 19종 블록 각각이 들어갈 자리 수 등으로 판을 평가합니다. 가중치는 시뮬레이션으로 튜닝했습니다.
3. **다음 턴 lookahead**: 상위 후보 배치마다 다음 턴 블록 3개를 여러 번 무작위로 뽑아, 그 상황에서도 잘 버티는 배치를 고릅니다. 성능에 가장 큰 영향을 주는 부분입니다.
4. **놓는 순서 최적화**: 최종 판이 같은 순서들 중에서 여러 줄 동시 삭제가 가장 많은 순서를 고릅니다. 생존에는 영향 없이 점수만 오릅니다.

시뮬레이션에서 확인한 내용:
- 다음 턴 후보 32 × 샘플 64 설정은 880턴 도달률이 52%입니다(블록 균등 분포 가정).
- 여러 줄을 일부러 모으도록 하면 오히려 50만 점 도달률이 떨어졌습니다. 그래서 생존 위주로 둡니다.
- 놓는 순서 최적화로 줄당 점수가 약 12% 올랐습니다.

실제 플레이에서는 이 헬퍼대로 두어 50만 점(635턴, 1,186줄)에 도달한 기록이 있습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `moamoa.html` | 서버 없이 열리는 단일 파일 헬퍼 (빌드 결과물) |
| `web/engine.js` | 탐색 엔진 JavaScript 버전 (`engine.c`와 결과 동일) |
| `web/local.js` | 브라우저 계산 로직 (Web Worker 병렬 lookahead) |
| `web/build.py` | `index.html` + JS 엔진 → `moamoa.html` 빌드 |
| `engine.c` | 탐색 엔진 C 버전 (OpenMP 병렬, 시뮬레이션·서버용) |
| `server.py`, `index.html` | 서버에서 띄우는 웹 버전 (C 엔진 사용) |
| `helper.py` | 터미널 버전 |
| `tune.py`, `bench.py` | 가중치 튜닝(Cross-Entropy Method)과 벤치마크 |
| `weights.json` | 평가 함수 가중치 |
| `dist_emp.json` | 단계별 블록 출현 확률 (실제 플레이 기록에서 추정) |

## 개발자용

```bash
# C 엔진 빌드 (Linux, gcc)
gcc -O3 -march=native -fopenmp -shared -fPIC -o libengine.so engine.c -lm

# 서버 버전 실행 → http://localhost:8765
python3 server.py

# 단일 파일 다시 빌드 (index.html, web/*.js, weights.json, dist_emp.json 수정 후)
python3 web/build.py

# 벤치마크: 256판, 50만 점 도달률 (블록 분포는 DIST로 지정)
DIST=dist_emp.json TARGET=500000 MAXT=3000 python3 bench.py weights.json 64,64,256,16,32,8,8,32
```

Python 쪽은 `numpy`만 필요합니다.
